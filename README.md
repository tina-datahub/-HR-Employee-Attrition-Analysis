# -HR-Employee-Attrition-Analysis


## Project Overview
This project focuses on analyzing employee attrition patterns using HR data to identify key factors influencing employee turnover. The analysis was performed using multiple tools including Excel, SQL, Python, and Power BI to build an end-to-end data analytics workflow.

The project covers:
- Data Cleaning & Transformation
- Exploratory Data Analysis (EDA)
- SQL-based Insights
- Statistical Analysis using Python
- Dashboard Creation in Excel
- Interactive Dashboard in Power BI
- Business Recommendations

---

## Objective
The main objective of this project is to understand:

- Why employees leave organizations
- Which employee groups show higher attrition
- Impact of overtime, salary, satisfaction, age, and departments on attrition
- Business recommendations to improve employee retention

# Key Insights

### Employee Attrition Summary

Total Employees:

1470

Employees Left:

237

Employees with overtime showed significantly higher attrition.

Research & Development and Sales departments recorded the highest attrition.

Younger employees and single employees were more likely to leave.

Employees with lower environment satisfaction had higher attrition.

Large salary differences existed among employees.

Employees with long promotion gaps also showed attrition patterns.

Research & Development department recorded the highest employee turnover.

Laboratory Technician and Sales Executive showed higher attrition counts.

# Business Recommendations

Based on analysis:

1. Reduce excessive overtime to improve retention.

2. Improve workplace environment and employee satisfaction.

3. Provide better career growth opportunities.

4. Review promotion cycles.

5. Focus retention strategies on younger employees.

6. Improve work-life balance initiatives.

7. Increase employee engagement in high attrition departments
# Conclusion

Employee attrition is influenced more by workload pressure, overtime, workplace environment, and growth opportunities than salary alone. Improving employee experience, engagement, and career progression can help organizations reduce attrition and improve retention.
